# PRD — AI Data Analyst Agent

**Project title:** AI Data Analyst Agent  
**Project type:** IBM / Hacktiv8 learning project  
**Implementation platform:** Langflow  
**Status:** Documentation draft based on workflow screenshots and supplied CSV  
**Version:** 1.0

## 1. Project objective

Build an AI-assisted workflow that processes customer product reviews from a CSV file and produces sentiment-related analysis, a concise summary of findings, and business action recommendations.

## 2. Business problem

E-commerce businesses can receive large volumes of customer reviews. Reading and synthesizing these reviews manually can be time-consuming and may lead to inconsistent interpretation.

## 3. Intended solution

The Langflow workflow accepts a customer-review CSV and uses prompt templates and language models to generate:
- Sentiment classification.
- A summary of findings.
- Action items / business recommendations.
- A chat output for the user.

## 4. Input dataset

The supplied `laptop_online_review.csv` is the dataset identified by the project owner as the same dataset used in the Langflow workflow. Despite its filename, the dataset includes multiple consumer-electronics product categories, including laptops, smartphones, and household appliances.

Audited properties:
- 1,001 records.
- 4 columns: `Unnamed: 0`, `Product_name`, `Review`, `Rating`.
- 108 unique product names.
- No missing values in the four columns.
- No exact duplicate rows.
- Ratings range from 1 to 5.

Rating distribution:
- 1: 57
- 2: 8
- 3: 58
- 4: 238
- 5: 640

The dataset contains customer reviews across multiple consumer-electronics product categories. The filename is not a reliable indicator of the full category scope.

## 5. Workflow components

Based on the supplied Langflow screenshot:
1. Read File — reads the uploaded review file.
2. Prompt Template — constructs the sentiment-analysis instruction.
3. Language Model — Gemini 3.1 Flash Lite, as displayed in the workflow screenshot.
4. Prompt Template — constructs the summary and action-item instruction.
5. Language Model — Gemini 2.5 Flash, as displayed in the workflow screenshot.
6. Chat Output — displays the generated response.

The workflow is a sequential LLM prompt-processing flow. Do not describe it as a vector-search RAG system, autonomous agent with tool calling, or multi-agent system; those capabilities are not evidenced in the supplied material.

## 6. Prompt design

The supplied screenshots show prompt instructions for:
- English internal reasoning instruction.
- Formal Bahasa Indonesia output.
- Sentiment labels restricted to Positive, Neutral, or Negative.
- Summary synthesis across product quality, performance/features, price/value, delivery/packaging, and overall satisfaction.
- Structured action items directed to relevant business departments.

An earlier prompt attempted strict JSON output and produced a Langflow Prompt Template validation error related to an invalid format specifier / nested braces. A later prompt version used a simpler narrative summary and sentiment output format. The screenshots show a successful generated response after this change.

## 7. Scope boundaries

In scope:
- CSV file ingestion.
- Prompt-based LLM processing.
- Sentiment-oriented analysis.
- Summary generation.
- Action-item generation.
- Chat output.

Not established by current evidence:
- Retrieval-Augmented Generation (RAG) or vector database.
- Quantitative sentiment model evaluation or accuracy.
- Automated sentiment labels stored for every row.
- Production deployment or API integration.
- Autonomous tool execution.
- Verified processing of every one of the 1,001 rows in a single model context.
